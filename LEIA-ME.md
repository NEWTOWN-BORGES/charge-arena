# APK de teste — Piloto Aurora modelado no Blender

`charge-arena-2.9.5-aurora-blender.apk` foi gerado a partir do PR #1 (commit e645b65).

- Aplicação: **Charge Aurora 3D** (`org.chargearena.blender`), instala-se ao lado das outras versões.
- Só arm64-v8a (telemóveis Android de 64 bits).
- Assinado com a chave de depuração do Godot: é só para testes.

No telemóvel: abrir o ficheiro .apk neste ramo no GitHub → **Download** → abrir e permitir
"instalar apps desconhecidas" quando o Android pedir.

Este ramo serve só para descarregar o APK e pode ser apagado depois.
